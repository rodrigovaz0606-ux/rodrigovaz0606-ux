## 📌 Projetos em destaque

### [Campo Certo — Gestão de Produtor Rural](https://github.com/rodrigovaz0606-ux/Campo_Certo)

Meu projeto mais completo: uma aplicação web que reúne cadastros rurais, autenticação de usuários e importação e conferência de notas fiscais eletrônicas.

- Cadastro e autenticação de usuários com JWT e hash de senhas.
- Gestão de produtores rurais, fazendas e participantes.
- Associação de fazendas a produtores, com propriedade única ou participação.
- Importação de múltiplos arquivos XML de NF-e ou de uma pasta inteira.
- Extração automática de data, número, valor, chave de acesso e emitente das notas.
- Conferência dos dados por produtor e fazenda em tabela editável.
- Download do XML original e exclusão de notas.
- Interface responsiva para computador e celular.
- Execução com Docker Compose e persistência do banco em volume.
- Teste automatizado do leitor de NF-e.

**Tecnologias:** JavaScript, React, Vite, Node.js, Express, SQLite, JWT, bcrypt e Docker.

[Acesse o código do Campo Certo](https://github.com/rodrigovaz0606-ux/Campo_Certo).

### [Livro Caixa RV](https://github.com/rodrigovaz0606-ux/LivroCaixaRv)

Aplicação web local de controle financeiro, desenvolvida em **Rust com SQLite**, para organizar as movimentações de um mercado.

- Cadastro, edição, exclusão e pesquisa de lançamentos.
- Organização por exercício anual.
- Cálculo de entradas, saídas e saldo.
- Transporte do saldo final para o exercício seguinte.
- Ajuste manual do saldo inicial.
- Valores monetários armazenados em centavos.
- Interface adaptada para computador e celular.
